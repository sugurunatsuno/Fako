# app

このフォルダーは、リポジトリ内で配布用の `Fako.exe` を置くためのプレースホルダーです。

- 自己完結版の `Fako.exe` は約 171MB あり、GitHub の 1 ファイル 100MB 制限を超えるため、
  リポジトリには含めていません。
- ビルド済みの配布物は [Releases](https://github.com/sugurunatsuno/Fako/releases) から取得してください。
  配布 ZIP では `Fako.exe` がルートにあります。
- ソースからビルドする場合は、リポジトリ直下で `.\install.ps1` を実行します（.NET 10 SDK が必要）。
