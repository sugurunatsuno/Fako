# app

このフォルダーの `Fako.exe`（自己完結版・約171MB）は、GitHub の 1 ファイル 100MB 制限のため
リポジトリには含めていません。ビルド済みの配布物は Releases から取得してください。

- Releases: https://github.com/sugurunatsuno/Fako/releases
- ソースからビルド: リポジトリ直下で `.\install.ps1`（.NET 10 SDK が必要）
- 配布用 ZIP の作成: `Fako-<version>-win-x64.zip` に `app\Fako.exe` とドキュメントを入れる
